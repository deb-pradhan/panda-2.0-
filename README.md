# Panda 2.0

Interactive announcement and landing page with 3D visuals.

## What is this?

Panda 2.0 is a visually rich announcement page built with React and WebGL. It features smooth animations, 3D graphics powered by OGL, and a polished design system — ideal for product launches and announcements.

## Features

- 3D WebGL visuals powered by OGL
- Smooth page animations with Framer Motion
- Custom design system with defined tokens and styles
- Responsive layout for all screen sizes

## Tech Stack

| Layer | Technology |
|-------|-----------|
| **Framework** | React + Vite |
| **3D Graphics** | OGL (WebGL) |
| **Animations** | Framer Motion |
| **Icons** | Lucide React |
| **Styling** | Tailwind CSS |

## Getting Started

```bash
git clone https://github.com/deb-pradhan/panda-2.0-.git
cd panda-2.0-
npm install
npm run dev
```
